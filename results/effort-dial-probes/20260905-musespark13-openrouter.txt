# meta/muse-spark-1.3 via OpenRouter (provider Meta, the only one listed) - reasoning-effort dial, 2026-09-05

VERDICT: INERT. Seven levels probed (parameter omitted, minimal, low, medium, high, xhigh, max), n=5 each
(max n=3), 32K max_tokens so no sample hit the cap. Every adjacent pair of levels OVERLAPS in range, no pair
separates (exact Mann-Whitney two-sided p >= 0.095 everywhere), the ordering is NON-MONOTONIC (the
omitted-parameter baseline reasons the MOST on average; xhigh reasons less than medium and high), and the
between-level ratio (2.38x on means) sits far inside the worst within-level spread (6.53x). Same signature as
muse-spark-1.2 on this path (n=3, 2026-08-06) and every other OpenRouter-served model probed on this board.
`minimal` is not a switch either: 2,394-9,784 reasoning tokens on the hard prompt, overlapping every other level.

TWO THINGS CHANGED SINCE AUGUST, and one of them retires a rule of thumb:
1. OpenRouter now VALIDATES `reasoning.effort` at the gateway against a global enum
   (max|xhigh|high|medium|low|minimal|none): `bogus_zzz` and `ultra` -> HTTP 400 "Invalid option: expected one
   of ...", and `none` -> HTTP 400 "Reasoning is mandatory for this endpoint and cannot be disabled." In August
   a garbage value returned 200 on this same path. So the rule of thumb recorded on 2026-08-06 - "garbage value
   -> 400 = somebody validates it = the dial is real" - NO LONGER DISCRIMINATES ON OPENROUTER: a 400 there proves
   OpenRouter's schema validator ran, not that the provider applied the value. Measuring is the only test left.
2. `max` is ACCEPTED on OpenRouter (200) although Meta's first-party endpoint 400-rejects it (first-party enum:
   low|medium|high|xhigh). On OpenRouter, `max` lands inside xhigh's range (8,532-10,442 vs 6,170-10,951) -
   consistent with the value being translated or dropped before it reaches Meta.

Meta first-party (api.meta.ai/v1/messages, `output_config.effort`) for muse-spark-1.3: still HTTP 402
"Billing verification failed" on 2026-09-05 - unchanged since 2026-08-06. That is the path where the dial was
shown to validate loudly and separate (1.2, 2026-08-06); it remains unavailable.

Consequence for the bench: an OpenRouter-served Muse Spark 1.3 arm runs at DEFAULT effort whatever the request
says; it must be published `effort=default`, `effort_status=inert_default`, never as xhigh or max.

Tool: the effort probe --transport openrouter --model meta/muse-spark-1.3 --provider Meta --max-tokens 32000
(temperature 0, seed 7, streaming; the default hard prompt = the corner-cut 5x5 tromino tiling count).
Discriminator = reasoning_tokens from usage.completion_tokens_details; correctness of the answer is irrelevant.
