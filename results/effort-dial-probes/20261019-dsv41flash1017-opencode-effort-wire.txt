DeepSeek V4.1 Flash 1017 in OpenCode - the effort on the wire, every request
Recorded 2026-10-18/19 for the OpenCode rows (max, high and low, n=5 each).

HOW
OpenCode 1.19.3 (opencode-ai, the open-source coding agent) talks to DeepSeek's OpenAI-compatible endpoint
(/chat/completions), like Pi and unlike the Claude Code and DeepSeek Harness rows. Its own model catalog lists
deepseek/deepseek-flash as DeepSeek V4.1 Flash 1017; `opencode run --variant <tier>` sends `reasoning_effort: "<tier>"`.
The same endpoint family validates the tier (see 20261017-dsv41flash1017-deepseek-effort.txt: low, high and max
accepted, an invented tier refused; each wave re-ran that gate before its first leg). A pass-through logger sat between
OpenCode and the API for every leg and recorded, per request, the model, reasoning_effort, the number of tools offered
and DeepSeek's usage. Requests are split by the tool set they carried: the main loop (9 tools), subagents started by
OpenCode's task tool (4 or 7 tools) and OpenCode's own session-title call (no tools).

READING
Every task request - main loop and subagents alike - carried its row's tier. The only exceptions are OpenCode's
session-title calls, one per leg, which it always sends at low; they generate a few words of title and touch no code.
OpenCode sends no separate `thinking` field; the model reasoned at every tier, as the usage shows. Per request, max
reasoned about as much as high (587 against 579 tokens) and both more than low (419).
